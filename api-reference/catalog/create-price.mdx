title: "POST /catalog/prices: Create a One-Time or Recurring Price"
sidebarTitle: "Create Price"
description: "Create a one-time or recurring price for a product in your PayGood catalog. Amounts are in cents. Reference the priceId in payments."
---

`POST /catalog/prices` creates a price for an existing product. Prices define the amount, currency, and billing type — either a single charge or a recurring subscription interval. Reference a `priceId` when creating a payment to tell PayGood how much to charge and how often.

## Endpoint

```
POST https://api.paygood.com/catalog/prices
```

## Request body parameters

<ParamField body="merchantId" type="string" required>
  The TypeID of the merchant creating the price. Begins with `mer_`.
</ParamField>

<ParamField body="productId" type="string" required>
  The TypeID of the product this price belongs to. Begins with `prod_`.
</ParamField>

<ParamField body="amount" type="integer" required>
  The charge amount in the smallest currency unit (cents for USD and CAD). For example, `2999` represents $29.99. Must be greater than `0`.
</ParamField>

<ParamField body="currency" type="string" required>
  ISO 4217 currency code. Supported values: `USD`, `CAD`.
</ParamField>

<ParamField body="type" type="string" required>
  The billing type. One of:
  - `one_time` — a single charge
  - `recurring` — a repeating charge on a set interval
</ParamField>

<ParamField body="interval" type="string">
  The billing interval. Required when `type` is `recurring`. Common values: `month`, `year`. Omit for `one_time` prices.
</ParamField>

## Examples

**Create a one-time price:**

```bash
curl -X POST https://api.paygood.com/catalog/prices \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "merchantId": "mer_01hxy...",
    "productId": "prod_01hxy...",
    "amount": 2999,
    "currency": "USD",
    "type": "one_time"
  }'
```

**Create a recurring monthly price:**

```bash
curl -X POST https://api.paygood.com/catalog/prices \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "merchantId": "mer_01hxy...",
    "productId": "prod_01hxy...",
    "amount": 999,
    "currency": "USD",
    "type": "recurring",
    "interval": "month"
  }'
```

## Response fields

<ResponseField name="priceId" type="string">
  The unique TypeID for the price. Begins with `prc_`. Use this when creating payments.
</ResponseField>

<ResponseField name="merchantId" type="string">
  The TypeID of the merchant that owns this price.
</ResponseField>

<ResponseField name="productId" type="string">
  The TypeID of the product this price is attached to.
</ResponseField>

<ResponseField name="amount" type="integer">
  The charge amount in the smallest currency unit (cents for USD and CAD).
</ResponseField>

<ResponseField name="currency" type="string">
  The ISO 4217 currency code, e.g. `USD` or `CAD`.
</ResponseField>

<ResponseField name="type" type="string">
  The billing type: `one_time` or `recurring`.
</ResponseField>

<ResponseField name="interval" type="string">
  The billing interval for recurring prices, e.g. `month` or `year`. `null` for `one_time` prices.
</ResponseField>

<ResponseField name="archivedAt" type="string">
  ISO 8601 timestamp of when the price was archived, or `null` if the price is still active.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of when the price was created.
</ResponseField>

## Response examples

**One-time price:**

```json
{
  "priceId": "prc_01hxy...",
  "merchantId": "mer_01hxy...",
  "productId": "prod_01hxy...",
  "amount": 2999,
  "currency": "USD",
  "type": "one_time",
  "interval": null,
  "archivedAt": null,
  "createdAt": "2026-03-15T10:00:00.000Z"
}
```

**Recurring monthly price:**

```json
{
  "priceId": "prc_01hxy...",
  "merchantId": "mer_01hxy...",
  "productId": "prod_01hxy...",
  "amount": 999,
  "currency": "USD",
  "type": "recurring",
  "interval": "month",
  "archivedAt": null,
  "createdAt": "2026-03-15T10:00:00.000Z"
}
```

<Note>
  Amounts are always in the smallest currency unit. For USD and CAD, that means cents — $29.99 is represented as `2999`, and $9.99 is `999`. Never pass decimal values.
</Note>
