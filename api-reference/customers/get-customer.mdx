---
title: "Retrieve a Customer by ID — PayGood Customers API"
sidebarTitle: "Get Customer"
description: "Retrieve a single customer record by TypeID. Returns the customer's name, email, entity type, phone number, and creation timestamp."
---

`GET /customers/{id}` retrieves a single customer by their TypeID. Use this endpoint to look up a customer's current details after creation or to verify that a customer record exists before initiating a payment.

```
GET https://api.paygood.com/customers/{id}
```

## Path parameters

<ParamField path="id" type="string" required>
  The TypeID of the customer to retrieve (`cus_...`). You receive this value as `customerId` when you create a customer.
</ParamField>

## Request example

```bash
curl https://api.paygood.com/customers/cus_01hxy8m1nqk9g3x3y3p0azq2bg \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY'
```

## Response fields

<ResponseField name="customerId" type="string">
  The unique TypeID of this customer (`cus_...`).
</ResponseField>

<ResponseField name="name" type="string">
  The full name of the customer.
</ResponseField>

<ResponseField name="email" type="string">
  The email address on file for this customer.
</ResponseField>

<ResponseField name="entityType" type="string">
  The entity type: `individual` or `business`.
</ResponseField>

<ResponseField name="phone" type="string">
  The customer's phone number. `null` if no phone number was provided at creation.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO-8601 timestamp of when the customer record was created.
</ResponseField>

## Response example

```json
{
  "customerId": "cus_01hxy8m1nqk9g3x3y3p0azq2bg",
  "name": "Jane Smith",
  "email": "jane@example.com",
  "entityType": "individual",
  "phone": "+15551234567",
  "createdAt": "2026-03-15T10:00:00.000Z"
}
```
