---

`GET /payments` returns a paginated list of payments for a given merchant, sorted newest first. Use the `cursor` parameter to page through results, and the `start` and `end` parameters to narrow results to a specific date range.

```
GET https://api.paygood.com/payments
```

## Query parameters

<ParamField query="merchantId" type="string" required>
  The TypeID of the merchant whose payments you want to retrieve (`mer_...`). All results are scoped to this merchant.
</ParamField>

<ParamField query="cursor" type="string">
  An opaque pagination cursor returned as `page.nextCursor` in a previous response. Pass this value to retrieve the next page of results.
</ParamField>

<ParamField query="limit" type="number">
  The maximum number of payments to return per page. Defaults to 20. Maximum value is `100`.
</ParamField>

<ParamField query="start" type="string">
  An ISO-8601 datetime string. Only payments created at or after this time are returned. Example: `2026-01-01T00:00:00.000Z`.
</ParamField>

<ParamField query="end" type="string">
  An ISO-8601 datetime string. Only payments created at or before this time are returned. Example: `2026-03-31T23:59:59.999Z`.
</ParamField>

## Request examples

Fetch the first page of payments for a merchant:

```bash
curl -G https://api.paygood.com/payments \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY' \
  --data-urlencode 'merchantId=mer_01hxy8m1nqk9g3x3y3p0azq2bg' \
  --data-urlencode 'limit=25'
```

Advance to the next page using a cursor returned from the previous response:

```bash
curl -G https://api.paygood.com/payments \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY' \
  --data-urlencode 'merchantId=mer_01hxy8m1nqk9g3x3y3p0azq2bg' \
  --data-urlencode 'limit=25' \
  --data-urlencode 'cursor=eyJ2IjoxLCJsYXN0SWQiOiJwbXRfMDFoeHk4bTFucWs5ZzN4M3kzcDBhenEyYmcifQ=='
```

Filter payments within a specific date range:

```bash
curl -G https://api.paygood.com/payments \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY' \
  --data-urlencode 'merchantId=mer_01hxy8m1nqk9g3x3y3p0azq2bg' \
  --data-urlencode 'start=2026-03-01T00:00:00.000Z' \
  --data-urlencode 'end=2026-03-31T23:59:59.999Z'
```

## Response fields

The response contains an `items` array of payment objects and a `page` object for pagination.

<ResponseField name="items" type="array">
  An array of payment objects, sorted newest first. Each object contains the following fields.

  <Expandable title="Payment object fields">
    <ResponseField name="paymentId" type="string">
      The unique TypeID of this payment (`pmt_...`).
    </ResponseField>

    <ResponseField name="idempotencyKey" type="string">
      The idempotency key supplied when the payment was created.
    </ResponseField>

    <ResponseField name="customerId" type="string">
      The TypeID of the customer who was charged.
    </ResponseField>

    <ResponseField name="merchantId" type="string">
      The TypeID of the merchant who received the payment.
    </ResponseField>

    <ResponseField name="paymentInstrumentId" type="string">
      The TypeID of the payment instrument that was charged.
    </ResponseField>

    <ResponseField name="priceId" type="string">
      The TypeID of the price associated with this payment.
    </ResponseField>

    <ResponseField name="captureMethod" type="string">
      The capture method used: `automatic` or `manual`.
    </ResponseField>

    <ResponseField name="processor" type="string">
      Indicates which payment processor handled this transaction.
    </ResponseField>

    <ResponseField name="amount" type="integer">
      The charged amount in the smallest currency unit (e.g., cents).
    </ResponseField>

    <ResponseField name="currency" type="string">
      The three-letter ISO currency code for this payment (`USD` or `CAD`).
    </ResponseField>

    <ResponseField name="status" type="string">
      The current payment status: `pending`, `authorized`, `captured`, `completed`, `voided`, `refunded`, or `declined`.
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      ISO-8601 timestamp of when the payment was created.
    </ResponseField>

    <ResponseField name="authorizedAt" type="string">
      ISO-8601 timestamp of when the payment was authorized. `null` if not yet authorized.
    </ResponseField>

    <ResponseField name="capturedAt" type="string">
      ISO-8601 timestamp of when the payment was captured. `null` if not yet captured.
    </ResponseField>

    <ResponseField name="voidedAt" type="string">
      ISO-8601 timestamp of when the payment was voided. `null` if the payment was not voided.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="page" type="object">
  Pagination metadata for the current result set.

  <Expandable title="Page object fields">
    <ResponseField name="hasMore" type="boolean">
      `true` if there are additional pages of results beyond the current one.
    </ResponseField>

    <ResponseField name="nextCursor" type="string">
      An opaque cursor to pass as the `cursor` query parameter in your next request. `null` when `hasMore` is `false`.
    </ResponseField>
  </Expandable>
</ResponseField>
