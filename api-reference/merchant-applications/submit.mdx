`POST /merchant-applications/{id}/submit` sends a completed draft application to the payment processor for KYB review. Once submitted, the application moves out of `draft` status and into the processor's review queue. Make sure all required sections are filled in before calling this endpoint.

## Endpoint

```
POST https://api.paygood.com/merchant-applications/{id}/submit
```

## Path parameters

<ParamField path="id" type="string" required>
  The application ID returned when you [created the draft](/api-reference/merchant-applications/create).
</ParamField>

## Pre-submission checklist

Before submitting, confirm you have completed all required sections using the [Update Application](/api-reference/merchant-applications/update) endpoints:

<Note>
  Your application must have all four sections filled in before you submit:

  - **Business profile** — legal name, business type, email, and registered address at minimum
  - **Beneficial owners** — all individuals owning 25% or more of the business
  - **Payout accounts** — at least one bank account for receiving payouts
  - **Underwriting data** — transaction volume estimates and card volume distribution
</Note>

## Example request

This endpoint requires no request body.

```bash
curl -X POST https://api.paygood.com/merchant-applications/mapp_01hxy4k2e3f5g6h7j8k9m0n1p/submit \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY'
```

## Example response

```json
{
  "id": "mapp_01hxy4k2e3f5g6h7j8k9m0n1p",
  "status": "submitted",
  "country": "US",
  "createdAt": "2024-06-01T12:00:00Z",
  "updatedAt": "2024-06-01T15:30:00Z"
}
```

## Checking application status

After submitting, poll `GET /merchant-applications/{id}` to track the application through the review process.

```bash
curl https://api.paygood.com/merchant-applications/mapp_01hxy4k2e3f5g6h7j8k9m0n1p \
  -H 'Authorization: Bearer $PAYGOOD_API_KEY'
```

## Application statuses

| Status | Description |
|---|---|
| `draft` | The application has been created but not yet submitted. You can still update any section. |
| `submitted` | The application has been sent to the payment processor and is awaiting assignment to a reviewer. |
| `under_review` | A reviewer is actively evaluating the application. |
| `approved` | The merchant has been approved and is able to process live payments. |
| `rejected` | The application was denied. The response will include details on the reason. |
| `amendments_requested` | The payment processor has requested corrections or additional information before approval. Update the relevant sections and resubmit. |

<Info>
  Review typically takes 1–3 business days. Poll `GET /merchant-applications/{id}` to check for status changes. We recommend checking once or twice a day rather than high-frequency polling.
</Info>
