PayGood is a REST API that gives you everything you need to accept payments. Whether you're building a marketplace, a SaaS billing system, or a point-of-sale integration, PayGood provides the primitives to move money reliably and at scale.

## Supported currencies

PayGood currently supports the following currencies:

- **USD** — United States Dollar
- **CAD** — Canadian Dollar

## Idempotent requests

All write operations (such as creating a payment or a customer) accept an `Idempotency-Key` header. Supplying a unique key lets you safely retry a request if you experience a network timeout or other transient error — PayGood will return the result of the original operation rather than creating a duplicate.
